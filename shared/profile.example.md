# Learner profile

Starting level not assessed yet. The Profile Bot runs the diagnostic at the first interaction.

## Scale
0 not started, 1 beginner, 2 elementary, 3 intermediate, 4 advanced, 5 mastery. Languages: CEFR (A1 to C2).
Level status: "declared" (said by the learner), "estimated" (diagnostic), "validated" (successful verification exercise reported by a teacher).
