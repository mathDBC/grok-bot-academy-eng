# Contributing

Improvements are welcome: prompts, profile format, new teachers, setup scripts.

1. Open an issue to describe the idea or the problem.
2. For a change, fork and open a short, focused pull request.
3. Never include personal data, keys or real learner profiles in a contribution.
4. For a new teacher, use the Builder Bot (`bots/builder-bot/`) or copy a file from `prompts/`, and keep the same rules: read the profile, structured session, verification exercise, mandatory report, no invention.
